For Desert Delivery's Studio Ghibli inspired hand-painted Mediterranean island overhaul, create a finely painted neutral ivory plaster/paper surface, softly mottled warm white and pale grey with subtle broad handmade gouache brush scumbles, flat orthographic evenly lit albedo, no lighting gradients, no objects, no borders, no text, no cracks.
