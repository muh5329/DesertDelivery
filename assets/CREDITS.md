# Asset credits

## Ground textures (assets/terrain)
All photo sets are from ambientCG (https://ambientcg.com, Lennart Demes), released under
Creative Commons CC0 1.0 Universal (https://docs.ambientcg.com/license/), obtained from the
GitHub release mirror https://github.com/Noisemaker111/jgengine/releases/tag/packs (1K JPG
variants), repacked to 512 px `*_alb_ht.png` (albedo, height in A) / `*_nrm_rgh.png` (normal,
roughness in A) by `world/mapgen/textures.py`.

| file base   | ambientCG id | use in the game |
|-------------|--------------|-----------------|
| rock019     | Rock019      | bedded limestone: rock overlay on slopes, base of the steepest faces |
| rock021     | Rock021      | streaked slabs: patches on the steepest faces |
| ground004   | Ground004    | trodden dry earth: the dirt roads |
| ground015   | Ground015    | dry straw grass: meadows, farm, moor |
| ground024   | Ground024    | stony scrub ground: limestone plateau, town |
| rocks002    | Rocks002     | rubble: talus at cliff feet |
| gravel009   | Gravel009    | fine gravel: road shoulders |

sand, clay, soil, salt are procedural (same script), no external source.

## Foliage cards (assets/foliage)
Generated by `world/mapgen/foliage.py`, no external source.

## assets/rock — ambientCG Rock019, Rock021 (CC0 1.0)
`rock019_alb.jpg`, `rock019_nrm.jpg`, `rock021_alb.jpg`, `rock021_nrm.jpg` are the 1K JPG Color and
NormalGL maps of ambientCG's Rock019 and Rock021 (https://ambientcg.com/view?id=Rock019,
https://ambientcg.com/view?id=Rock021), by Lennart Demes, released under Creative Commons CC0 1.0
Universal (https://docs.ambientcg.com/license/). Obtained via the GitHub-release mirror
https://github.com/Noisemaker111/jgengine/releases/tag/packs (copied from /root/assets_pool/ambientcg).
Used by `world/kit/rock.gdshader` (triplanar albedo + normal on the RockGen limestone pieces).

## September 2026 storybook overhaul

`assets/storybook/gouache_surface.png` is an ImageGen-generated original surface. See
`assets/storybook/README.md` for the exact generation prompt and usage. It now supplies
Terrain3D albedo paint; the credited older normal maps remain at reduced strength.
The rounded `courier_truck.glb` was authored through Blender MCP from the project-owned
`tools/blender/storybook_truck.py`. Existing project GLBs retain their provenance and
received material/vertex-paint treatment; Quaternius tree meshes retain their CC0 credit.

## Character reference revision

The courier was rebuilt in Blender from the user-supplied character turnaround (`Codex Image Sep 1, 2026, 09_52_41 PM.png`). Source: `assets/source/courier_reference.blend`; reproducible generator: `tools/blender/character.py`. The original supplied turnaround is preserved under `assets/source/courier_turnaround.png` (excluded from game import). Its front facial detail is projected and blended in Blender into the courier’s packed 1K facial albedo; the remaining geometry and materials are authored by the generator. The original full turnaround is not loaded by gameplay.
