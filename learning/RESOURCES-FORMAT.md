# Format: RESOURCES.md

A curated list, not a bookmark dump. Every entry earns its place.

```
## <Area>

### <Title> — <author or publisher>
- **Link:** <url>
- **Type:** reference / book / course / video / community
- **Trust:** primary (the thing itself) / secondary (a good reading of it) / unverified
- **Use it for:** the specific question this answers
- **Read:** not yet / skimmed / worked through
```

Rules:
- **Primary sources first.** The engine's own docs beat a blog post about the engine.
- Anything marked `unverified` must not be cited in a lesson.
- Record what it is *for*. A link without a use is noise.
