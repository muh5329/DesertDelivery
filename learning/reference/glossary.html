Design vocabulary

The words used to talk about the shape of this code. Grows by at most two per lesson. For what the words in the game mean — Rider, Hub, Ring, Recipe — see CONTEXT.md in the repo.

Introduced so far

Interface — lesson 01
Everything a caller must know to use a module correctly: the signature, but also ordering constraints, invariants, error modes, required configuration and performance characteristics. Here: GroundDrive's interface includes "set intent and mods before calling step()" — an ordering rule no type enforces. Don't say: API, signature. Both are narrower — they mean only the type-level surface, and the expensive part of an interface is never the types.
Seam — lesson 01
A place where you can alter behaviour without editing in that place. (Michael Feathers.) Here: Controls.Source. Swap Keyboard for Scripted and the bike's physics is unchanged and unaware — which is why the test suites drive the real bike rather than a copy of it. Don't say: boundary. It is overloaded with DDD's "bounded context" and will send a reader somewhere else.

Not yet introduced

Listed so you know the shape of what is coming, and so you can ask for one early if you hit something it would explain. Do not try to learn these from this list — they need a lesson each.

Module
Anything with an interface and an implementation, at any scale.
Depth
Leverage at the interface: how much behaviour you get per unit of interface you must learn.
Adapter
A concrete thing that satisfies an interface at a seam.
Leverage
What callers get from depth.
Locality
What maintainers get from depth: change concentrating in one place.
The deletion test
Imagine deleting the module. Does complexity vanish, or reappear in five callers?
One inherited definition we reject

Ousterhout's A Philosophy of Software Design is where "deep module" comes from, and it is worth reading — but it measures depth as the ratio of implementation lines to interface lines. That rewards padding the implementation. Here, depth means leverage: behaviour gained per unit of interface learned. Same word, different measure. If you read the book, do not import the ratio.
