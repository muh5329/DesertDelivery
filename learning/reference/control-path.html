The control path

Key to motion, in five handovers. Print this. From Lesson 01.

The chain

InputMap
W → the action accelerate project.godot · edited in the editor · 18 actions today
Controls.Keyboard
actions → Controls.Reading gameplay/controls/controls.gd · the only reader of Input
Scheme
Reading → Controls.Intent Controls.Foot · Vehicle.GroundScheme · Bike.BikeScheme · Truck.TruckScheme
Rider
state commands, then vehicle.apply(i) or player.apply(i) entities/player/rider.gd · the only module that reads a raw Intent
GroundDrive
step(delta) → speed, yaw, pitch, grounded entities/vehicles/ground_drive.gd · tunables from data/vehicles/*.tres

Where do I put it?

A new key binding
InputMap only. No code.
A new command (a press)
Constant in Controls, name into ACTIONS, press it in a Scheme, react to it in the Rider or the vehicle's apply().
A key that means something new while driving X
X's Scheme. Nowhere else.
A key that works everywhere
The two universal commands live in Keyboard.read(): INTERACT, RESET. Add there only if it truly has no owner.
Something that changes Mode
The Rider. Mount, dismount, wings, reset — transitions are its job alone.
Something that changes how it drives
data/vehicles/*.tres first. Only touch GroundDrive if no field exists for it yet — and then add the field, not a branch.
Cargo, fuel or upgrades affecting handling
The vehicle's _drive_mods(). Never inside the drive.
The step everyone forgets

If an action name is not in Controls.ACTIONS, then r.just() and r.down() return false for it forever, with no error. The Reading only carries what that list polls. When a new control silently does nothing, check this first.

Reading vs Intent

Controls.Reading
What you did. forward, back, side, run, aim, look, look_back, mouse_captured, plus held / pressed per action. Ask it: r.just(&"horn") — fired this tick. r.down(&"handbrake") — being held.
Controls.Intent
What it meant. throttle, brake, steer, pitch, boost, handbrake, move, cargo_move, plus named commands. Ask it: i.pressed(Controls.WINGS). Set it: i.press(Controls.WINGS).

The commands

JUMP · FIRE · INTERACT · WINGS · RESET · WINCH · CARGO_MODE · CARGO_PLACE · CARGO_ROTATE · CARGO_REMOVE

All declared at the top of gameplay/controls/controls.gd. Commands are edge-triggered: true for exactly one tick, then cleared by clear_edges().
